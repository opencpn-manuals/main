Detailed Description

template<typename T>
class conn_edit::Reloadable< T >

Interface implemented by widgets reflecting a ConnectionParams parameter.

The widget is kept in sync with the parameter(s) at any time using a contract:

  • When created, widget state is updated from parameters.
  • WHen user modifies widget state parameter(s) is updated.
  • When external code changes the parameter(s) it invokes Reload() which synchronizes widget state with parameters.

@Note: This interface is used by Reload() which traverses the window tree. Thus a Reloadable should be a wxWindow subclass and not for example a sizer; this is checked at compile time.
